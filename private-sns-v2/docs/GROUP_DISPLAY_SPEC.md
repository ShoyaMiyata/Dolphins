# グループ一覧表示仕様

## 概要

SNSアプリケーションにおけるグループ一覧の表示仕様を定義します。グループ一覧はヘッダーのハンバーガーメニュー内に表示されます。

## 表示場所

- **コンポーネント**: `AppHeader` (ヘッダー)
- **UI要素**: ハンバーガーメニュー内の「グループ」セクション
- **表示形式**: ドロップダウン形式のリスト

## 表示対象グループ

### 自然言語での整理

**プライベートグループの表示条件：**

「プライベートグループは、そのグループに招待されて正式に参加している（アクティブなメンバーである）ユーザーのみに表示される。」

具体的に言うと：
- グループオーナーによって招待されたユーザー
- 招待を受け入れて参加を承認したユーザー
- 現在もそのグループの有効なメンバーであるユーザー

**パブリックグループの表示条件：**

「パブリックグループは、ログインしている全てのユーザーに表示される。」

具体的に言うと：
- 誰でも参加できる公開グループ
- メンバーシップの状態に関係なく全員に見える

### 技術的な条件

ユーザーに表示されるグループは以下の条件を満たすものに限られます：

1. **プライベートグループ**: ユーザーがアクティブなメンバーであるグループのみ
   - `group_members.user_id = ユーザーID`
   - `group_members.is_active = true`
   - `groups.visibility_type = 'private'`

2. **パブリックグループ**: 全てのユーザーに表示
   - `groups.visibility_type = 'public'`

### 表示除外条件

以下のグループは表示されません：
- 非アクティブなメンバーのプライベートグループ
- 招待待ちのグループ（`is_active = false`）
- 参加申請中のグループ（承認待ち）

## 表示順序

- **ソートキー**: `created_at` (作成日時)
- **ソート順**: 降順（新しいグループが上）
- **重複処理**: プライベートとパブリックの両方に該当する場合、重複表示を避ける

## 表示内容

### 各グループの表示要素

1. **グループアイコン**
   - 優先順位: カスタム画像 > デフォルトアイコン
   - デフォルト: 青い背景のグループアイコン

2. **グループ名**
   - 表示: グループの `name` フィールド
   - スタイル: 省略表示対応
   - 最大長: 制限なし（UIで省略）

3. **プライベート表示**
   - 条件: `visibility_type = 'private'`
   - 表示: 鍵アイコン (🔒)
   - 位置: グループ名の右側

4. **メンバー数** (非表示)
   - データ上は取得しているが、UIには表示しない

## インタラクション

### クリック動作

- **遷移先**: `/groups/[groupId]`
- **パラメータ**: `groupId` (グループのID)
- **動作**: 該当グループの詳細ページに遷移
- **メニュー閉じる**: クリック時にハンバーガーメニューを閉じる

### メニュー操作

- **展開/折りたたみ**: 「グループ」ヘッダーをクリックで切り替え
- **作成ボタン**: 「+」ボタンでグループ作成ダイアログ表示

## データ取得仕様

### APIエンドポイント

- **フック**: `useGroups()`
- **クエリ**: リアルタイム取得（React Query）

### 取得ステップ

1. **メンバーシップ取得**
   ```sql
   SELECT group_id, role FROM group_members
   WHERE user_id = $user_id AND is_active = true
   ```

2. **メンバーグループ取得**
   ```sql
   SELECT * FROM groups WHERE id IN ($member_group_ids)
   ```

3. **パブリックグループ取得**
   ```sql
   SELECT * FROM groups WHERE visibility_type = 'public'
   ORDER BY created_at DESC
   ```

4. **データ統合**
   - メンバーグループ + パブリックグループ
   - 重複除去
   - 詳細情報追加（オーナー情報、メンバー数など）

### エラーハンドリング

- **ネットワークエラー**: 空のリストを表示
- **認証エラー**: ログイン画面へリダイレクト
- **個別グループ取得エラー**: そのグループのみスキップ

## UI/UX仕様

### レイアウト

- **最大表示数**: 制限なし（スクロール対応）
- **スクロール**: 縦スクロール対応
- **高さ**: 最大200px
- **余白**: 適切なパディング

### ビジュアルスタイル

- **背景色**: 白 (#ffffff)
- **ホバー効果**: 薄いグレー背景
- **アイコンサイズ**: 20x20px
- **テキストサイズ**: 14px (sm)
- **行高**: 9 (h-9)

### アクセシビリティ

- **キーボード操作**: Tabキーでの移動可能
- **スクリーンリーダー**: 適切なラベル付与
- **フォーカス表示**: 視覚的なフォーカスインジケーター

## パフォーマンス考慮

### キャッシュ戦略

- **React Query**: デフォルトキャッシュ使用
- **無効化タイミング**: グループ作成/更新/削除時
- **リアルタイム性**: 定期リフェッチなし（イベント駆動）

### 最適化

- **クエリ数**: 最小限（3つのクエリ）
- **並行実行**: Promise.all使用
- **メモ化**: React Queryのキャッシュ活用

## セキュリティ考慮

### データアクセス制御

- **RLS適用**: SupabaseのRow Level Security
- **ユーザー分離**: ログインユーザーのデータのみ取得
- **権限チェック**: メンバーシップ確認

### プライバシー保護

- **プライベートグループ**: メンバーのみに表示
- **招待制**: 非メンバーは表示されない
- **情報漏洩防止**: グループ詳細はメンバーのみアクセス可能

## テストケース

### 正常系

1. **パブリックグループのみ**: 全ユーザーに表示
2. **プライベートグループ**: メンバーのみに表示
3. **混合グループ**: 両方の条件を満たすグループを表示
4. **新規作成**: 作成直後に一覧に表示

### 異常系

1. **ネットワークエラー**: 空リスト表示
2. **認証切れ**: ログイン画面遷移
3. **データ破損**: エラーログ出力、該当グループスキップ
