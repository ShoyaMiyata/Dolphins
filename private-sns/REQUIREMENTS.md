# Dolphins (Private SNS) 要件定義書

## プロジェクト概要

**プロジェクト名**: Dolphins (Private SNS)
**目的**: 公開範囲を気にせず、安心して使える完全プライベートなSNS
**ターゲットユーザー**: 友人・家族・親しいコミュニティ内での情報共有を求める全世代

---

## 1. プロジェクトの背景と目的

### 1.1 背景
- 既存SNS（Instagram、Twitter）は公開範囲の設定が複雑
- 意図しない拡散や炎上のリスク
- プライバシーへの懸念が増加
- 本音で投稿できる場所が欲しい

### 1.2 目的
- 完全にプライベートな空間での安心感
- Instagram/Twitter風の使いやすいUI/UX
- シンプルで分かりやすい機能
- 気軽に投稿できる環境

## 4. UI/UX要件

### 4.1 デザインコンセプト
- **シンプル**: 必要最小限の機能に絞る
- **洗練**: モダンで美しいデザイン
- **安心感**: プライベートであることが分かる配色・デザイン

### 4.2 カラースキーム
- **プライマリカラー**: パープル〜ピンクのグラデーション（#9333EA → #EC4899）
- **背景**: 淡いグラデーション（パープル/ピンク/ブルー）
- **カード**: 白背景 + 半透明効果（Glassmorphism）
- **テキスト**: ダークグレー（#111827）

### 4.3 レイアウト
- **モバイルファースト**: シングルカラム
- **最大幅**: 640px（タイムライン）
- **固定ヘッダー**: スクロール時も表示
- **ボトムナビゲーション**: モバイル用（ホーム、通知、プロフィール）

### 4.4 コンポーネント
- **ボタン**: ラウンドコーナー、グラデーション
- **カード**: 影付き、ラウンドコーナー
- **アバター**: 円形、グラデーション背景（画像なしの場合）
- **入力フィールド**: ラウンドコーナー、フォーカス時のリング

## 6. データモデル

### 6.1 主要テーブル

#### profiles
```sql
- id: UUID (Primary Key, Foreign Key to auth.users)
- username: TEXT (Unique, Not Null)
- display_name: TEXT
- avatar_url: TEXT
- bio: TEXT
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### posts
```sql
- id: UUID (Primary Key)
- user_id: UUID (Foreign Key to profiles)
- content: TEXT
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### post_images
```sql
- id: UUID (Primary Key)
- post_id: UUID (Foreign Key to posts)
- image_url: TEXT (Not Null)
- order_index: INTEGER (Not Null)
- created_at: TIMESTAMP
```

#### likes
```sql
- id: UUID (Primary Key)
- post_id: UUID (Foreign Key to posts)
- user_id: UUID (Foreign Key to profiles)
- created_at: TIMESTAMP
- UNIQUE(post_id, user_id)
```

#### comments
```sql
- id: UUID (Primary Key)
- post_id: UUID (Foreign Key to posts)
- user_id: UUID (Foreign Key to profiles)
- content: TEXT (Not Null)
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### reposts
```sql
- id: UUID (Primary Key)
- post_id: UUID (Foreign Key to posts)
- user_id: UUID (Foreign Key to profiles)
- created_at: TIMESTAMP
- UNIQUE(post_id, user_id)
```

#### reactions
```sql
- id: UUID (Primary Key)
- post_id: UUID (Foreign Key to posts)
- user_id: UUID (Foreign Key to profiles)
- emoji: TEXT (Not Null)
- created_at: TIMESTAMP
- UNIQUE(post_id, user_id, emoji)
```

#### follows
```sql
- id: UUID (Primary Key)
- follower_id: UUID (Foreign Key to profiles)
- following_id: UUID (Foreign Key to profiles)
- created_at: TIMESTAMP
- UNIQUE(follower_id, following_id)
```

#### notifications
```sql
- id: UUID (Primary Key)
- user_id: UUID (Foreign Key to profiles)
- type: TEXT (Not Null) -- 'like', 'comment', 'repost', 'follow', 'reaction'
- related_user_id: UUID (Foreign Key to profiles)
- related_post_id: UUID (Foreign Key to posts, Nullable)
- is_read: BOOLEAN (Default: false)
- created_at: TIMESTAMP
```
